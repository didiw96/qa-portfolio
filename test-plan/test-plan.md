# Test Plan — Hospitality Management System

## 1. Objective

Validate that the core hospitality system functions according to business requirements and acceptance criteria.

## 2. Scope

- Booking Engine
- Property Management System (PMS)
- Point of Sale (POS)
- Inventory
- Purchasing
- Finance
- Housekeeping

## 3. Testing Types

- Functional Testing
- Smoke Testing
- Regression Testing
- Retesting
- Integration Testing
- API Testing
- Negative Testing

## 4. Test Environment

- Environment: Staging
- Browser: Google Chrome
- API Testing: Postman
- Database Validation: SQL

## 5. Entry Criteria

- Build deployed to staging
- Requirements available
- Test environment accessible
- Test data prepared

## 6. Exit Criteria

- Planned test cases executed
- Critical defects resolved or accepted
- Regression testing completed
- Test results documented

## 7. Risk Areas

- Financial calculations
- Inventory quantity
- Booking availability
- Night Audit
- Payment and cashier summary
- Cross-property data access
